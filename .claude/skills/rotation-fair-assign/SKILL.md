# ローテ公平アサイン（POC）

## 目的

21営業日サイクルの **日別：当番 × テーマ（Value枝）** 案を出す。  
最終採否・手直しはトシオ。ノートへコピーして共有面に載せる。

## 入力

- アクティブなメンバー一覧
- Value枝カタログ
- 直近おおよそ **2周分**の履歴（日付×当番×テーマ）
- 新サイクル開始日・営業日数（既定21）
- 乱数シード（再シャッフル用）

## 生成ルール（初版）

1. **当番の間隔**: 同一サイクル内の連続・偏りを避ける
2. **クールダウン**: 当番後 **約7営業日** は空けやすい配置にする
3. **テーマの多様性**: その人の直近2周の担当テーマと重複しにくい
4. **全体バランス**: 1サイクル内で特定メンバー・特定テーマに偏りすぎない
5. **手直し前提**: 結果は案。差し替え可能

休日カレンダーは POC では扱わない（土日スキップのみ）。

## 出力

- 日付ごとの `{ date, memberId, valueItemId }`
- 可能なら警告（クールダウン未達件数、0回メンバーなど）
- ノート用テキスト（日付 / 当番 / テーマ）

## 実装対応

アプリ: `src/lib/rotation/fair-assign.ts`（`fairAssign`）
