# 最終チェック（投稿前）

通読・コピーの直前に走らせる。アプリの「最終チェック」と同じ物差し。

## アプリ

段階「通読」で **最終チェック** → `checkFinalReviewPost`（決定論）。  
error があるときはコピー前に直す。

## Cursor でサブエージェントに見るとき

投稿文を渡して、次を短く報告させる（実装・スキル名は本文に書かせない）:

1. 「行動指針について」が **2回以上**ないか
2. 「想いを共有頂きました」の二重がないか
3. 「ですね／ますね」がないか
4. お礼 → Value要約 → 所感 →（任意♯）→ 締め の順か
5. 要約のあいだに Value帯名／指針全文の再掲がないか

不合格なら **修正案（要約行だけ）** を1つ出す。
