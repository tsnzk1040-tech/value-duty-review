# 評価シナリオ（drafting-daily-reviews）

スキル改訂時に、最低このセットで「構成・要約・同テーマ引用」が甘くないか見る。  
構成 → [structure.md](structure.md) ／ 同テーマ → [same-theme-quote.md](same-theme-quote.md)

## 1. 具体が短い投稿

**入力**: 接客で名前を覚えて声をかけた／反応がよかった、程度の短い投稿＋呼び名。  
**期待**: お礼→Value要約1段落→所感→締め。原文コピペや空の褒めだけにしない。

## 2. 長い・定型が混ざる投稿

**入力**: 「本日の…」定型や次回担当つきの長文。  
**期待**: 次回テーマ行を要約の主役にしない。メタ行を本文に入れない。

## 3. リンクあり／なし

**入力**: 同じ投稿で、リンク採択ありとなし。  
**期待**: ありなら `♯タイトル`＋URL。なしでも構成は成立（リンク必須にしない）。

## 4. 同テーマ前回 — bridge 引用

**入力**: 同テーマの履歴に、要約あいだが実践事実として残っている前回レビューがある。今日の投稿・要約がその実践と自然につながる。  
**期待**: 所感に『同テーマ前回の〇〇さんの共有にあった、「…」』が入る。「…」は前回**要約**の実践事実（所感・共感文ではない）。末尾は通じる／重なる系でも可。所感欄上のステータスが引用あり。

## 5. 同テーマ前回 — summary 空＋全文切り出し／または引用なし表示

**入力 A**: 履歴の `summary` は空だが、`fullText` に要約定型（について、〜共有頂きました）がある。  
**期待 A**: 全文から要約あいだを切り出して引用できる（出典は要約。所感段落は含めない）。

**入力 B**: 同テーマ履歴が無い、または要約あいだが切り出せない／bridge・intro とも無理。  
**期待 B**: 所感本文に無理な引用を入れない。所感欄上に「前回要約の引用なし: …」理由が表示される。
