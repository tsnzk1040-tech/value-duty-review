# 毎日レビュー — 出力の味（SSoT）

構成の並び・各ブロックの必須／任意は **[structure.md](structure.md)** が正。  
本ファイルは **言い方・合格感**だけを持つ。

## 方針

**要約** = リーダー理解の体裁で、**浸透リレー実践の事実**を見せる（120〜180字・やや客観・落ち着いたです・ます）。  
**所感** = 今日も一歩進んだ**実感**・引きつけ・次の一歩。  
カジュアル寄せはしない（「ですね」が出やすい）。管理本部の前提は**解釈ガイドのみ**。「ですね」禁止。

## 要約の合格（ゆるい）

- 定型のあと、行動指針本文／Value帯名の再掲なし
- **120〜180字**程度で洗練（所感の足しすぎ・メタコメント禁止）
- 理解を深める行為＋自分に取り入れる実践を、評価なしで拾う
- 「一歩前進」「浸透が進んだ」等の実感フレーズを書かない（所感の仕事）
- 「共有」の二重・「ですね」を作らない

## 所感の合格（ゆるい）

- 投稿の具体かテーマに触れている
- 職場グループ向け。減点口調にしない
- 実践がチームの前進につながる実感が、無理なく読み取れる
- 長くてもよいが、締めの呼びかけまで届くこと

## 不合格の典型

- 投稿全文コピペ＋ラベルだけ
- 要約に褒め・実感フレーズを載せすぎる
- 実装メモ（「POC」「スタブ」等）が本番文に残る
- お礼や Value 要約を飛ばす
- 参考リンクを必須扱いにして無理に捏造する（任意）
