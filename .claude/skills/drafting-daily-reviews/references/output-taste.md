# 毎日レビュー — 出力の味（SSoT）

構成の並び・各ブロックの必須／任意は **[structure.md](structure.md)** が正。  
同テーマ前回の引用ルールは **[same-theme-quote.md](same-theme-quote.md)** が正。  
本ファイルは **言い方・合格感**だけを持つ。

## 方針

**要約** = リーダー理解の体裁で、**浸透リレー実践の事実**を見せる（120〜180字・やや客観・落ち着いたです・ます）。  
**所感** = 上司として寄り添うカジュアルな距離感。共感・ほめ → 同テーマ前回（same-theme-quote）→ キーワード検索の結果の主要な箇所を引いた「こうしたら？」（芯は「所感の提案の狙い」）。ほめは投稿の具体に寄せる。  
**締め** = 奨励しつつ考える余白。所感の提案は復唱しない。号令・スローガン不可。  
「だね／だよ」は避ける。要約側は「ですね」禁止。所感・締めの共感「ですね」は可。

## 人が書いた文に見せる（全ブロック共通）

要約・所感・締め・同テーマ引用の自由文に効かせる。正本は `src/lib/review/human-voice.ts`。お礼・Value の枠・検索結果の書き出し（今日のコメントに関連したキーワードを検索した結果によると、）・「想いを共有頂きました！」は定型のまま。締めの文末は「！」と「。」のどちらも可（背中を押す文は「！」、受け止める文・難しさを認める文・静かな問いは「。」）。

- 例文の言い回し・書き出しを写さない
- 投稿の言葉を拾う。硬い漢語や決まり文句（まさに／素晴らしい／〜ではないでしょうか／〜につながります）に寄せない
- 投稿に無い程度・感情を盛らない
- 三つ並べ・対句・記号（——、：、箇条書き）で整えない
- 所感の一文目を毎回「いいですね」で始めない。締め3案は形をそれぞれ変える
- 投稿に無い相手の気持ちを推測しない（嬉しかった・青ざめる等）。落ち込みの強い投稿は、書かれた事実を一度だけ受け止めて本人の行動へ移る
- ほめる文は投稿の具体に寄せる。「いいですね」で受けてよい。毎回同じほめ言葉にしない
- 例文の骨格は写されやすい。プロンプトの良い例は最小限にする（所感の良い例は検索から先だけ）

## 提案と締めの重み

- 所感の検索結果は、主要な箇所を「」で引く（原文に近い言い回し・30〜60字）。一般論（コミュニケーションが大切）にしない
- 提案の芯は「所感の提案の狙い」。提案の動作・人数・期間は引用に合わせる
- 提案の宛先は既定でチーム全体（「我々も、」）。役割が限られるときだけ一定の対象者（「〇〇の方は、」15字以内）。結びは「〜してみたらどうでしょう。」
- 提案は、いつ・どの場面で・何をするかの二つ以上が見える小さな動き。「意識してみる」「共有する」だけで終えない
- 提案の形は日ごとに変える（手順を一つ足す／基準をそろえる／確認のタイミング／相手への一言／迷ったときの問い）
- 締めは軽い励まし（十分です／それだけで前進／頭の片隅に）で閉じない。投稿者の具体か行動指針の意味に一度触れる
- 締め3案は、行為の意味を返す／難しい場面を認めて余白を残す／メンバーへの静かな問い、の違う向きから
- 3案目は問いの形で終える（「〜てみてください」にしない）。「！」は多くて1案で、送り出し・期待の文だけ。言い切りには付けない

## 要約の合格（ゆるい）

- 定型のあと、行動指針本文／Value帯名の再掲なし
- **120〜180字**程度で洗練（所感の足しすぎ・メタコメント禁止）
- 理解を深める行為＋自分に取り入れる実践を、評価なしで拾う
- 前半の文末は投稿の動詞に合わせる。毎回「捉えなおしていました」にしない。温度のために中身を別の行為へ書き換えない
- 「一歩前進」「浸透が進んだ」等の実感フレーズを書かない（所感の仕事）
- 「共有」の二重・「ですね」を作らない

## 所感の合格（ゆるい）

- 投稿の具体に共感・感謝がある（ですね可・話しやすい）
- 同テーマ前回は [same-theme-quote.md](same-theme-quote.md) に従う（要約あいだのみ／bridge→intro／意味閉じ。形式的な接続だけ・理念文言再掲は不合格）
- 今日のテーマに自然につながっている（コード全文なし・訓示なし）
- メンバー全体か一定の対象者への「こうしたら？」が1点（キーワード検索の結果を根拠に織る。記事要約が半分以上を占めない。『調べた要点』は出さない）
- 個人の「明日××してみましょう」で終わらない
- 宣教師っぽい標語（理念浸透・指針の実践・体現・チームの力 等）が前面に出ない

## 不合格の典型

- 投稿全文コピペ＋ラベルだけ
- 要約に褒め・実感フレーズを載せすぎる
- 所感が参照記事の要約になっている
- 所感が布教・訓話になっている
- 所感が個人宿題（明日の一件で試して）で終わる
- 締めが所感の「こうしたら？」の言い換えになっている
- 実装メモ（「POC」「スタブ」「要点メモ」等）が本番文に残る
- お礼や Value 要約を飛ばす
- 参考リンクを必須扱いにして無理に捏造する（任意）
- 同テーマ前回の引用が same-theme-quote の禁止事項に当たる（所感転用・今日の所感コピー等）
