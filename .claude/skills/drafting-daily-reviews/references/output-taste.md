# 毎日レビュー — 出力の味（SSoT）

構成の並び・各ブロックの必須／任意は **[structure.md](structure.md)** が正。  
本ファイルは **言い方・合格感**だけを持つ。

## 方針

**シンプルな要約＋少し褒める。** 触りながら直してよい。

## 要約の合格（ゆるい）

- 原文の丸投げ／先頭カットだけの「要約」にしない
- 発表者以外が、原文なしでも今日の要点を追える
- 攻め・皮肉にしない（少し褒める）

## 所感の合格（ゆるい）

- 投稿の具体かテーマに触れている
- 職場グループ向け。減点口調にしない
- 長くてもよいが、締めの呼びかけまで届くこと

## 不合格の典型

- 投稿全文コピペ＋ラベルだけ
- 実装メモ（「POC」「スタブ」等）が本番文に残る
- お礼や Value 要約を飛ばす
- 参考リンクを必須扱いにして無理に捏造する（任意）
