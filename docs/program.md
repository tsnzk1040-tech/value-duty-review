# 全体企画（value-duty-review）

企業理念の浸透リレーを、管理本部の日常運用として無理なく回し続けるための自分用モバイル Web アプリ（表示名：**企業理念リレー**）。

## ゴール（目指す状態）

- 通勤の短い時間で、当番メンバーの振り返り投稿に対する **毎日レビューの下書き** と、月1回の **公平な日別ローテ設計** を迷わず完了できる。
- 返信が一辺倒・布教調にならず、メンバーの実践事実を認めながら「明日の小さな動き」や「考える余白」を届け続けられる。
- リポジトリとアプリの正本（SSoT）が常に現実と一致しており、AI に1行頼むだけで最新方針に沿った改善・運用ができる。

## 現在地（いまの状態とインサイト）

- **稼働中の機能**：Next.js App Router（16）＋ Gemini API ＋ 端末 `localStorage` で本番稼働中（`/review`・`/rotation`・`/history`・`/settings`・`/login`・PWA 共有 `/share-target`）。
- **インサイト（矛盾する気持ち）**：
  - やりたい気持ち：AI っぽさや宣教師みたいな布教調を防ぎ、現場に刺さる自然な返信を出したい。
  - 詰まっていること：変な出力を防ぐために定型と禁止ルールを足し算し続けた結果、所感が毎回同じ流れになりマンネリ化している。

## 戦略（力を入れること／やらないこと）

### 力を入れること

1. **正本（SSoT）を一本にし、現実で上書きする**：企画・現在地・ルール・実データの置き場を分け、同じことを2か所に書かない。古くなった記述は残さず上書きし、経緯は Git 履歴に任せる。
2. **「足す」から「引く＋お手本」へ**：所感の禁止ルールを整理し、型を明確に分けた複数案と理想の実例（お手本）でバリエーションを出す。
3. **秘密情報をリポに置かない安全設計**：実名・理念全文・実チャット・API キーはコードやドキュメントに含めず、端末側・環境変数に閉じる。

### やらないこと

- 社内許可のないチャット自動取得・自動投稿（コピペ／PWA 共有の往復で止める）。
- 外部 DB への常駐保存（端末 `localStorage`＋JSON バックアップで完結させる）。
- 理念の標語や訓話を押しつける「宣教師口調」の返信。
